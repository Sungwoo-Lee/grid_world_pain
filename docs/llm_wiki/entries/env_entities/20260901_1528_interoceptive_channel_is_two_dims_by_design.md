# The interoceptive channel is 2 dimensions, and injury is hidden by design

## Key conclusion
`injury_observable: false` and `nutrition_observable: false` are **designed defaults**, not
oversights. The agent never sees ground-truth injury; it perceives body state only through
**Satiation** and **Interoceptive Nociception**, a tonic, delayed percept of hidden injury.
Any plan to feed "injury and nutrition" to a modulator must be restated in terms of these
two proxies.

## Evidence, measurements, facts
- `configs/environment/default.yaml:255-257` — both observability gates false, under the
  comment "Hidden-state observability gates".
- `src/environment/sensor.py:482-522` — `get_observation_breakdown` gates each sensor.
- Built `basic/04-jump_attack_10x10` and `sensory_directional/A_baseline`: obs_dim **27**,
  action_dim 6, broken down as Satiation 1, Interoceptive Nociception 1, Extero Nociception 1,
  Olfaction 5, Collision 5, Proprioception 6, Visual 8. `location_sensor_enabled: false`.
- So: **interoceptive 2 dims, exteroceptive 19, efference 6.**
- Interoceptive Nociception is the hidden injury convolved with an alpha kernel,
  k_raw[i] = (i/tau)*exp(1 - i/tau), normalised to sum 1, with **k[0] = 0** so there is no
  instantaneous leak. tau = 3, kernel length 12. The felt signal therefore **peaks ~3 steps
  after** the damage and decays over ~12.
- Consequence for any modulator reading this channel: it reads **felt** pain (biologically the
  correct input for a neuromodulator) but inherits a ~3-step lag, so it cannot react on the
  step damage occurs.
- Extero Nociception is a *pain* signal but classed exteroceptive (phasic, multi-source
  contact) — so a "nociceptive" grouping (intero + extero noci) is a different cut from the
  intero/extero split.

## Decisions and actions
- Turning the observability flags on was **ruled out**: it would dissolve the
  nociception-versus-pain distinction the project rests on.
- The 2-factor experiment's interoceptive input arm is defined as Satiation + Interoceptive
  Nociception (2 dims), not "injury and nutrition".
- Verified by **building the environment**, not by reading YAML — consistent with the recorded
  lesson that deep-merge and sensor gating make config reading unreliable.

## Open questions and follow-ups
- The 3-step percept lag is untested as a factor; it may matter for any behaviour that must
  respond to damage promptly.
