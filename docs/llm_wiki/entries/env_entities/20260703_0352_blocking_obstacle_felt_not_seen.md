# Blocking obstacle is "felt, not seen": perceived via the collision sensor + bump-pain, invisible to vision/smell

## Key conclusion
Setting a rock's `blocking: true` really does stop the agent (`move_agent` returns the old position on a collision), and it changes WHICH sensory channels reveal the rock. A BLOCKING rock is perceived only through: (1) the COLLISION sensor — a 5-cell Manhattan diamond `[center, Up, Right, Down, Left]` that reads `1.0` in the direction of an adjacent blocking rock OR a grid edge (out-of-bounds); it is PROACTIVE (fires before the agent bumps) and directional; and (2) extero-nociception, which fires the rock's nociception_intensity + damage ONLY when the agent actually bumps it. A blocking rock is INVISIBLE to the visual channel because `visual_sensor_range: 0` means visual sees only the agent's own cell, and the agent can never stand on a blocking cell. It also emits no olfaction (default rock properties are all 0). A NON-blocking rock is the mirror image: the agent walks onto it, SEES it (visual channel 6, on-contact) and takes overlap-nociception, but it does NOT register in the collision sensor (that sensor only reports blocking rocks + OOB).

## Evidence, measurements, facts
- Verified in-env: agent at (5,5) tried to move Right into a blocking rock at (5,6) -> stayed at (5,5); with blocking:false it moved onto (5,6).
- Collision direction map (blocking rock in each neighbour): Up->[0,1,0,0,0], Right->[0,0,1,0,0], Down->[0,0,0,1,0], Left->[0,0,0,0,1] (index 0 = own cell). Fires before the bump.
- On a bump: extero-nociception = rock nociception_intensity (0.9) + injury from damage [1,5]; interoceptive (tonic) pain rises over subsequent steps.
- Code: move_agent collision (core.py); sense_collision (sensor.py, uses obs_blocking & obs_active + OOB); sense_extero_nociception (last_collision_noc). visual range 0 is the reason it is never seen.

## Decisions and actions
- Design implication for the predator-strategy / bush-hiding experiments: blocking rocks add a TACTILE/navigational environment feature (felt via the collision channel), distinct from the VISUAL bush-hiding the agent already uses. If you want the agent to SEE walls (not just feel them at range 1) you would need a larger visual_sensor_range (which changes obs_dim) or a rock smell — a deliberate change.
- No config was changed by this investigation (blocking stayed off in the live configs); this is mechanism understanding.
