# Olfactory distance weighting (decay_power) sets distal-cue strength

## Key conclusion
The olfactory sensor weights each entity's smell by **1 / dist^decay_power** (capped at 2.0 on-cell),
summed over entities within `sensor_radius`. The default **decay_power = 2.0 (inverse-square)** makes smell
fall off steeply (weight ~0.11 at 3 cells) — this is *why* the distal olfactory cue is weak and the agent
can't pre-empt an approaching animal. Re-running the whole sweep with **decay_power = 1.0 (linear)** makes
smell carry farther (~0.33 at 3 cells) for advance warning — a direct test of whether a longer-range cue
enables pre-emptive avoidance.

## Evidence, measurements, facts
- `src/environment/sensor.py:5` `sense_resource`: `decay = where(dist < 0.001, 2.0, 1 / dist^decay_power)`;
  `mask = res_active AND dist <= radius`; `weighted_props = property * decay * mask`, summed. Same function
  serves resources, animals, and obstacles.
- `configs/environment/default.yaml`: `sensor_radius: 20` (whole 10x10 grid), `decay_power: 2.0`. So the
  hard radius is not the limiter — the steep exponent is. Weights: 1.0 @ dist1, 0.25 @ dist2, ~0.11 @ dist3
  (decay 2.0) vs 1.0 / 0.5 / 0.33 (decay 1.0).
- Linear-decay configs: `configs/environment/experiment/olfactory_ambiguity_lindecay/` — each nested-`extends:`
  its olfactory_ambiguity twin and overrides ONLY `sensory.decay_power: 1.0` (diff-clean; decay_power is a
  traced JAX leaf, no recompile).
- **CAVEAT (load-bearing):** decay_power is GLOBAL to the olfactory sensor — it lengthens the range of ALL
  smells (food + obstacles too), not just the animals'. The paired comparison is still clean (the baseline
  differs only in decay_power), but a survival gain could partly come from easier foraging.

## Decisions and actions
- Launched the 10-config linear-decay sweep (wandb group `hunger_gated_lindecay`, seed 42) as a paired
  comparison against the decay-2.0 baseline ([[20260622_1745_discrimination_weak_lethality_masks_gating]]).
- Identified `decay_power` (and secondarily `sensor_radius`) as the lever for distal-cue strength, the
  knob that addresses the "olfaction is the only distal cue and it is weak" finding.
