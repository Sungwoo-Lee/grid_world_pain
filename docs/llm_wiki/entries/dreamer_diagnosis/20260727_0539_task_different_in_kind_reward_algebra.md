# Our grid world vs the DreamerV3 suite: different in kind; death is the only controllable signal

## Key conclusion

The professor-level comparison refused both "simpler" and "harder" as one-word answers. Simpler on every axis the DreamerV3 benchmarks discriminate on (~90% conf): no exploration problem, 6 actions, ≤500-step episodes, 27-dim input (≈ DMC-proprio, the suite's cheapest member). Harder IN KIND on axes the suite barely tests (~85%): visual_sensor_range 0 (agent sees only its own cell), olfaction radius > grid diagonal so smell is a global superposition not a gradient, injury (the death-determining variable) unobservable behind a 3-step proxy, hiding predators emit zero smell (irreducible aleatoric lethality), per-episode hidden dynamics params (predator count U{0,1,2}, damage [15,120], detect range U{1..7}) = a Hidden-Parameter MDP, and start_injury ~ U[0,100] makes some episodes unwinnable at t=0. The deepest algebraic finding: the dense homeostatic reward is ≈ Φ(s')−Φ(s) (near-potential-based → nearly policy-invariant); the controllable return reduces to the discounted death term — a SPARSE-CATASTROPHE task in a dense-reward costume, a shape nothing in Atari/DMC/Crafter/Minecraft has. "Harder overall" is NOT currently defensible (~35%) because the achievable ceiling has never been measured.

## Evidence, measurements, facts

- At Dreamer's γ=0.997 the death term dominates the controllable return ~5:1; symlog/two-hot handles the −100 scale fine (that worry refuted, ~10%).
- rPPO's 2.6B-step plateau is WEAK difficulty evidence (~25%) because of the γ=0.95 surrogate problem ([[20260727_0540_rppo_gamma095_myopic_survival_surrogate]]).
