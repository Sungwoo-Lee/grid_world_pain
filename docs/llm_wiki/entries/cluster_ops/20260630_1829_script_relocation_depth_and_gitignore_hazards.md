# Two silent hazards when relocating a script into a subfolder

## Key conclusion
Moving a script one directory deeper breaks two things that have NOTHING to do with who calls it, so they are easy to miss:
1. **`__file__`-depth repo-root math.** Scripts that compute the repo root by a fixed number of parent hops (`Path(__file__).resolve().parent.parent`, or `os.path.dirname(os.path.dirname(__file__))`) now resolve one level too shallow once the file is one level deeper, so `sys.path.insert(repo_root)` + `from src...` fails. Each relocated file must gain one hop (`parents[2]` / triple-`dirname`). Symptom of a miss: `ModuleNotFoundError: No module named 'src'` when running the moved script.
2. **`.gitignore` pattern collision.** A top-level ignore pattern that matches the new subfolder *name* will silently make the moved files untracked. Here the repo ignored the WandB run dir via `wandb/`, which also matched the new `scripts/wandb/`; the moved files never got tracked until the pattern was anchored to repo root (`/wandb/`).

## Evidence, measurements, facts
- 31 scripts relocated into `scripts/{wandb,eval,dreamer,claude,lab,media}/`; every relocated `.py` with `__file__`-root math needed a depth bump. `scripts/dreamer/sheeprl_jax_diff.py` had ~30 identical `sys.path` lines — all needed the +1 hop.
- The two folders that were already one level deep (`scripts/behavior_measures/`, `scripts/verification/`) already compensate with `parents[2]` / triple-`dirname` — a ready template for the moved files.
- `.gitignore` had a bare `wandb/`; `git check-ignore scripts/wandb/wandb_utils.py` confirmed the collision. Fix = anchor to `/wandb/`; afterwards `git ls-files scripts/wandb/` shows all 4 files tracked.
- Verification gate that catches a missed depth fix: smoke-run one script per new subfolder on the conda interpreter `/home/vncuser/miniconda3/envs/grid_world_pain/bin/python` — none threw `No module named 'src'`.

## Decisions and actions
- The reorg plan made the per-file depth fix a mandatory column of the move table; the per-phase verification gate is a smoke-run per subfolder.
- Anchored `.gitignore` `wandb/` → `/wandb/` (only intended change to `.gitignore`).
