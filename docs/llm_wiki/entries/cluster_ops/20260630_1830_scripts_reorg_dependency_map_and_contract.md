# Map-before-move + group-by-function + Maintenance Contract for a script-folder reorg

## Key conclusion
A safe way to reorganize a flat `scripts/` pile: (1) first build a caller-dependency map across ALL FOUR reference surfaces — intra-folder Python imports, `src/` subprocess paths, the test suite, and Claude skills/agents/settings — plus the `__file__`-depth hazard; (2) group **by function**, not by lifecycle/caller, because the strongest physical coupling (bare-name Python imports) is functional, so a functional layout keeps import clusters co-located and needs zero import edits; (3) wire a **Maintenance Contract** into `CLAUDE.md` + the `developer`/`senior-developer` profiles so the map is updated in the same change whenever `scripts/` change — reusing the existing CONFIG_GUIDE contract pattern.

## Evidence, measurements, facts
- `docs/environment/SCRIPTS_DEPENDENCY_MAP.md` covered the 4 surfaces and revealed: training is nearly decoupled from `scripts/` (only `launch_sheeprl.sh` matters); the WandB scripts (`wandb_utils`/`wandb_metrics`/`compare_wandb_runs`/`benchmark_wandb_speed`) use **bare-name imports** so must stay co-located; `render_recordings.py` has 2 hardcoded `src/` subprocess paths; 2 test pins; `diary_append.py` has 7 callers; 2 settings-allowlist pins.
- Chose group-by-function over group-by-lifecycle specifically because lifecycle would split the WandB bare-import cluster and the eval pipeline → forced import rewrites; function keeps them whole (0 import edits).
- Maintenance Contract mirrors [[20260619_0114_config_guide_maintenance_contract]] (CONFIG_GUIDE wired into 5 agent profiles).
- Outcome: 31 `git mv` relocations into `scripts/{wandb,eval,dreamer,claude,lab,media}/` + 2 `git rm` of disposable one-shots; senior-developer verdict **PASS-WITH-NITS** — every subfolder smoke-runs clean; the only failing test (`test_offline_wm_smoke`) is a pre-existing `--num-starts 5` vs floor-50 threshold mismatch, byte-identical pre/post-move, not reorg-induced.

## Decisions and actions
- Adopted map-before-move + group-by-function + Maintenance Contract as the approach. Orphans relocated; 2 disposable one-shots (`migrate_dev_frontmatter.py`, `rewrite_dev_links.py`) `git rm`'d; import conventions left as-is (co-location keeps bare imports working).
- Per-file depth fixes and caller-reference updates pulled directly from the map; see hazard companion [[20260630_1829_script_relocation_depth_and_gitignore_hazards]].
