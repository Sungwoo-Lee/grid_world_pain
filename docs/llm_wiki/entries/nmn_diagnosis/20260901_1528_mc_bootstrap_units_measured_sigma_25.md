# The MC window-edge bootstrap delivers ~4% of its intended correction

## Key conclusion
The critic is trained against returns z-scored per window, but its raw output is used as the
starting value of a backward accumulation over **un-normalised** rewards. Measured, the
starting value arrives at roughly **1/25 of correct magnitude**, so the H4 fix is ~96%
inert — and the residual under-crediting reaches about 35% of all training targets.

## Evidence, measurements, facts
- Chain: `bootstrap_value = v_boot` (`recurrent_ppo_trainer.py:311-314`, raw head output) ->
  seeds `compute_mc_returns` (`:95-135`) which accumulates raw rewards -> returns are
  z-scored (`:378`) and become the critic target (`:379`).
- **Measured across four recorded rollouts** (`results/trajectories/20260810-*_rppo_restprem_a07..a10`):
  per-step reward std ~7.4; raw MC return **sigma 22.8-25.1**, consistent across runs;
  per-window sigma median 11, p10 3.4, p90 29. Reward min -165, max +39.
- Reach is gamma^k * (1 - 1/sigma), material (>10% of target std) for the last ~45 steps of
  each 128-step window — matching the diagnosis's analytic 25-40% estimate.
- MC advantages are **not** re-normalised (the GAE branch does normalise), so the artefact
  reaches the policy gradient directly, not only the critic.
- **Corrects an earlier assumption**: the homeostatic reward is near-telescoping, but this does
  NOT make raw returns small — `calculate_drive` is a Euclidean distance in raw units
  (satiation and injury each 0-100), spanning ~0-141.
- **Corrects the registry**: the H4 Fixed row warns that pre-H4 runs are not comparable to
  post-H4 runs. Since the starting value is ~1/25 scale, post-H4 targets are numerically close
  to pre-H4 ones — that caveat is roughly 4% true.

## Decisions and actions
- Root cause adopted: **normalise advantages, not returns** — making the MC branch structurally
  identical to the GAE branch already in the file. This resolves the units bug and the
  moving-affine-target problem (diagnosis Finding 3) together.
- **Known cost, deliberately accepted and measured rather than assumed**: raw targets make the
  value gradient ~25x larger while `clip_by_global_norm(0.5)` remains global over the whole
  tree, so the actor can be throttled as collateral damage. A four-condition gate was
  pre-registered rather than a single median test.
- User decision: all runs retrain fresh; pre-fix and post-fix runs are not compared.

## Open questions and follow-ups
- Return sigma on `basic/04` is unmeasured — the figures above come from rest-premium
  recordings. `loss/value_target_std` post-fix is the first in-situ measurement.
- Whether the global clip actually binds is unknown until measured.
