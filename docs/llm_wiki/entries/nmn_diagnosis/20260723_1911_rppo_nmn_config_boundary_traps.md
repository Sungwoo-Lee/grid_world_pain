# rPPO-NMN: forward is correct, the danger is at the config boundary

## Key conclusion

The first-ever dedicated end-to-end audit of the live rPPO-NMN (neuromodulated) path found the **modulated forward pass correct and train-equals-eval identical** (empirical probe: max |delta logits| 5e-4, float32 noise) — modulator state and params ride the audited hidden-state and checkpoint contracts everywhere. All the debt is at the **config boundary**, where several silent traps distort interpretation of past runs or would silently disable features in future ones. The highest-value finding: **`agent.lr_critic` is a dead key in every rPPO config — the critic AND the modulator have always trained at `lr_actor` (0.0005), not the advertised 0.0001** — so any reasoning about NMN learning dynamics from the YAML learning rate is wrong. Second: there is **no heteroscedastic / Kendall-&-Gal auxiliary loss in the live rPPO stack at all**; total loss is exactly `policy + vf*value + ent*entropy` and the modulator trains solely through the shared PPO loss. The `*_het_*` config family means the perceptual-noise **heterogeneity** sweep, not heteroscedastic regression — a recurring naming-driven misreading (this session's own earlier framing included).

## Evidence, measurements, facts

- `lr_critic` dead: `train.py:509,796-803` — critic and modulator optimizers built from `lr_actor`; the advertised 0.0001 never applied.
- No aux loss: total loss `src/models/recurrent_ppo_trainer.py:184`.
- Unknown `modulation.type` (e.g. `"Film"` capitalized) silently builds a Multiplicative net (no beta heads, gamma bias 3.0, no error) — no whitelist (`recurrent_ppo_network.py:211-218`, probe-verified).
- Dead knob: `percept_bias_init: 3.0` dead in all 11 live FiLM configs (code forces gamma bias 1.0); siblings `unimodal_overrides`/`fc_layers` also unread on rPPO.
- Missing/typo'd `agent.modulation` block silently trains baseline (`train.py:767-771`); eval mirrors it, so no train/eval divergence.
- Verified sound: modulator forward identical train vs eval; heteroscedastic assumption REFUTED (does not exist); memory_clip enforced; temp floor 0.5; entropy on temperature-scaled logits is intended.
