# Noise-trained agents need a noise-matched frozen probe

## Key conclusion
When a frozen-checkpoint behavior probe is run on an agent that trained with sensory noise, the probe config must replicate that agent's training noise, or it measures the agent out of its trained regime (a clean probe makes a noise-trained agent look wrong). This extends the sensory-match principle (match decay_power / sensory to the eval model, [[20260622_1745_frozen_probe_eval_match_sensory_renderer]]) to **perceptual observation noise**.

## Evidence, measurements, facts
- v5 (`rppo_basic05v5_allnoise`) and later basic06/basic07 train with two noise components: (1) a top-level `perceptual_noise:` block — 10 modalities, `enabled: true`, per-modality `mode` (constant / state_dependent), `sigma`, `injury_noise_scale` (e.g. olfaction σ=0.15/scale=4.0, visual σ=0.1/scale=2.0, injury/nutrition scale=1.5); and (2) animal `properties_std: [0,0.4,0.4,0,0]` (per-episode smell-source σ on the two olfactory channels).
- The clean avoidance probe has neither → mis-measures. A noise-matched set was built (`explore/avoidance_stat_noise/` for the 30-seed heatmap, `explore/avoidance_noise/` for seed-42 videos): each extends its clean counterpart and adds the verbatim `perceptual_noise` block + `behavior_measures.eval_obs_noise: training` + entity σ 0.4.
- **Pipeline verified to apply the noise**: `src/environment/sensor.py::apply_perceptual_noise` is gated on `params.perceptual_noise_enabled`; `get_observation(apply_noise=True)` noises the agent's obs while `true_obs` is recorded with `apply_noise=False`; `config_loader` reads `perceptual_noise.enabled/.modalities` and `behavior_measures.eval_obs_noise`. Sanity check: on the noise probe the agent obs differed from `true_obs` at EVERY step (mean |Δ|≈0.05, max 1.2).
- basic06_noise and basic07 have `perceptual_noise` IDENTICAL to v5, so the same noise probe was reused (no new configs).
- Behavioral effect the clean probe would have hidden: on the noise probe the `entered bush` column gains huge variance (±42–50) and even the no-animal condition sometimes hides — injury-scaled noise makes internal readings unreliable, so the agent hides inconsistently.

## Decisions and actions
- Clean probe for no-noise models (basic05 variants, NMN); noise-matched probe for v5 / basic06 / basic07.
- 24 noise configs created + committed (b535395); `env-config-auditor` pass recommended before the final post-training run.

## Open questions and follow-ups
- Entity smell-σ (0.4) is a secondary component; the dominant match is the agent-facing `perceptual_noise` block.
- If a future noise model uses a DIFFERENT perceptual_noise recipe, a new matched probe set is needed (diff the block first).
