# Regime-matched probe for bush-refuge agents + run_sweep probe-dir path

## Key conclusion
The standard avoidance probe (`core/avoidance/`) gives the bush `hides_agent: true` but NOT `blocks_animals`. Probing a `rppo_bushrefuge` agent (trained with the bush blocking predators) on that standard battery is OFF-REGIME: it removes the refuge the agent expects, so a predator would follow it into the bush and the probe understates its avoidance. The matched probe adds `obstacles[bush].blocks_animals: true` to all 12 conditions. This extends the sensory/regime-match principle to a physics/env feature.

## Evidence, measurements, facts
- Created `configs/environment/experiment/behavior_probes/core/avoidance_bushrefuge/` — 12 configs auto-derived from `core/avoidance/` by injecting `blocks_animals: true` after each bush's `hides_agent: true` line (verified: config loads, bush blocks_animals=True).
- Patched `scripts/eval/dwell_sweep/run_sweep.py::probe_dir()`: besides the `clean`/`noise` presets it now treats any other `spec.probe` value as a repo-relative probe-dir path (`REPO_ROOT/probe` if it is a directory, else ValueError). Backward compatible.
- Spec `configs/eval_sweeps/bushrefuge_rppo.yaml` uses `probe: configs/environment/experiment/behavior_probes/core/avoidance_bushrefuge`.
- On the matched probe the bushrefuge agents survive far better than any agent on the standard probe (b04 pred_inj70 45.9 vs Dreamer curriculum ~9) — the match matters. Commit `af46e99`.

## Decisions and actions
- User chose the matched probe (over standard/both) when the fork was surfaced pre-launch.
- `run_sweep` probe-dir-path support is the reusable mechanism for any future regime-matched sweep (noise, bush-refuge, or a new env feature).
