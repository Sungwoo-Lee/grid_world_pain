# dreamer-srl v3 — CP3 Math Review

## Verdict (plain language)

**Purpose.** Second of three sequential reviewer gates on the third checkpoint of the dreamer-srl v3 rebuild. The checkpoint ports a tiny piece of math: at construction time, force both the reward head and the critic head to be *literally zero* on every weight and every bias. This sounds trivial, but it is the canonical Hafner fix used in the DreamerV3 reference (and propagated through sheeprl as "cascade fix #27"). The intuition is that a two-hot 255-bin logit head with random-init weights produces structured, high-magnitude logits at step 0; the loss latches onto those logits before any learning has happened, and the world model never quite recovers. Zero-init the output linear and the head starts as the maximum-entropy uniform distribution over the 255 bins — no spurious early gradient, no early-step credit-assignment leak.

Code-reviewer already confirmed (a) the implementation uses CP1's `uniform_init_weights(scale=0.0)` helper, (b) both call sites in sheeprl are cited correctly (`agent.py:L1172` critic, `L1175` reward), and (c) bit-identity tests pass at `max_abs_diff = 0.000e+00` against fixtures generated by the vendored sheeprl helper. My job is to verify that the *math* — the scale-zero degenerate uniform, the zero-logit-implies-uniform-distribution claim that justifies the fix — actually holds, and that the JAX expression reduces to true zeros (not e.g. a denormalized-float near-zero, not NaN, not `-0.0` with hidden sign trouble).

**Headline.** The math reduces cleanly to literal zero. The Hafner uniform formula $\ell = \sqrt{3s/d_\text{avg}}$ collapses to $\ell = 0$ when $s = 0$, and `jax.random.uniform(key, minval=0.0, maxval=0.0)` returns the constant zero array regardless of the key — no edge cases fire at fan-in $= 512$, no division-by-zero, no NaN, no negative-zero ambiguity. Softmax of a zero logit vector is exactly $1/N$ on every bin (uniform). The implementation is faithful, the algorithmic justification is sound, and no platform deviation is needed.

**Outcome.** No findings. No deviations to log (zero is platform-invariant). **Verdict: PASS.** Professor may fire next.

## Equations under review

### Eq. 1 — `uniform_init_weights` at the degenerate scale

The CP1-audited Hafner uniform initializer is

$$W_{ij} \;\sim\; \mathcal{U}[-\ell,\,+\ell], \qquad \ell \;=\; \sqrt{\frac{3 s}{d_\text{avg}}}, \qquad d_\text{avg} \;=\; \tfrac{1}{2}(d_\text{in} + d_\text{out}). \tag{Eq.~1}$$

CP3 evaluates this at $s = 0$ (sheeprl call sites: `agent.py:L1172` critic, `L1175` reward — both pass `scale=0.0`). Substituting:

$$s = 0 \;\Longrightarrow\; \ell = \sqrt{\frac{3 \cdot 0}{d_\text{avg}}} = 0 \;\Longrightarrow\; W_{ij} \sim \mathcal{U}[0,\,0] \;\Longrightarrow\; W_{ij} = 0 \;\;\forall\, i, j. \tag{Eq.~1'}$$

The bias is set separately to `jnp.zeros((out_features,))` — not routed through Eq. 1.

### Eq. 2 — Softmax of zero logits is uniform

A two-hot reward / value head produces logits $z \in \mathbb{R}^{N}$ with $N = 255$ bins, then the categorical distribution over bins is

$$p_k \;=\; \frac{e^{z_k}}{\sum_{j=1}^{N} e^{z_j}}. \tag{Eq.~2}$$

At init, $z = W^\top h + b = 0$ (since $W = 0$, $b = 0$ regardless of the hidden activation $h$). Substituting $z_k = 0$ for all $k$:

$$p_k \;=\; \frac{e^{0}}{\sum_{j=1}^{N} e^{0}} \;=\; \frac{1}{N} \;=\; \frac{1}{255} \quad \forall\, k. \tag{Eq.~2'}$$

This is the maximum-entropy uniform distribution over the bin support. Cross-entropy under this prior is $\log N \approx 5.541$ nats for any target — flat, uninformative, no preferred direction in logit space. Exactly Hafner's design intent.

### Eq. 3 — Expected gradient at init is bounded and symmetric

For the two-hot cross-entropy loss $\mathcal{L} = -\sum_k y_k \log p_k$ with target $y$ a (possibly soft) probability vector summing to 1, the logit gradient is

$$\frac{\partial \mathcal{L}}{\partial z_k} \;=\; p_k - y_k. \tag{Eq.~3}$$

At init, $p_k = 1/N$, so $\partial \mathcal{L} / \partial z_k = 1/N - y_k$. With $N = 255$ this is bounded in $[-1 + 1/N,\, 1/N]$ — small, symmetric, no large pre-trained direction. The kernel gradient $\partial \mathcal{L} / \partial W = h \otimes (p - y)$ then has typical magnitude $\|h\| \cdot \mathcal{O}(1)$ — bounded by the hidden activation scale, not by random-init logit magnitude. This is the contrast that makes cascade fix #27 a *fix* rather than a cosmetic detail.

## Critical-points audit (math-side)

### Critical point 1 — `uniform(-0, 0)` is the constant-zero distribution

The Python expression `jax.random.uniform(key, minval=0.0, maxval=0.0)` is well-defined: JAX implements `uniform` as $u = a + (b - a) \cdot r$ for $r \in [0, 1)$ a raw uniform draw, so when $a = b = 0$ the formula simplifies to $u = 0 + 0 \cdot r = 0$ identically. There is no $0/0$, no NaN, no key-dependent path. With `minval = -limit = -0.0`, JAX treats `-0.0` and `+0.0` as equal in floating-point comparison (IEEE 754: $-0 == +0$), so the result is the canonical positive-zero array. The test's `jnp.max(jnp.abs(jax_kernel - jnp.asarray(torch_kernel)))` would catch any negative-zero asymmetry (it would still report `0.0`, since `|−0| == 0`, but downstream `==` checks against torch's `0.0` succeed because IEEE equates the two).

**Verified.** No NaN/inf risk. No sign trouble. The degenerate uniform is the constant zero.

### Critical point 2 — fan-in edge cases are not exercised

The general formula $\ell = \sqrt{3s / d_\text{avg}}$ would divide by zero if $d_\text{in} + d_\text{out} = 0$. CP3 uses $d_\text{in} = 512$, $d_\text{out} = 255$, so $d_\text{avg} = 383.5$ — no zero-fan risk fires at this checkpoint. Even if a future caller passed $d_\text{in} = 0$ deliberately, the numerator `given_scale = 0` would short-circuit before the division mattered (`0 / 0` would NaN, but `0.0 * np.sqrt(...)` would not — and the actual code path is `scale = 0/d`, `limit = sqrt(3*scale) = sqrt(0) = 0`, which is well-defined as long as $d \ne 0$). Documented for completeness; not a CP3 concern.

**Verified.** $d_\text{in} = 512$, $d_\text{out} = 255$, $d_\text{avg} \gg 0$.

### Critical point 3 — algorithmic justification (Hafner's reasoning)

DreamerV3 represents reward and value as discrete categorical distributions over 255 two-hot bins. A randomly initialized output linear $W \sim \mathcal{N}(0, \sigma^2)$ with $\sigma^2 \sim \mathcal{O}(1/d_\text{in})$ produces logits with standard deviation $\sim \|h\| / \sqrt{d_\text{in}}$ — small per element, but **structured**: certain bins systematically get larger logits than others, depending on the random projection of $h$. The softmax of this structured non-uniform vector then concentrates probability mass on a few bins, away from the true (initially unknown) reward / value distribution. The cross-entropy gradient $\partial \mathcal{L} / \partial z = p - y$ then has a *direction* — pointing toward the random-init's spurious peak — and the optimizer takes a real step in that direction before any meaningful credit signal has arrived from the environment.

Zero-init the output linear and this disappears: $z = 0$, $p = \mathbf{1}/N$, gradient $p - y = \mathbf{1}/N - y$ which has zero preferred direction in the kernel-rotation sense (it shifts probability mass uniformly toward $y$, with no spurious "random peak" to unlearn). The world model can now train against an unbiased prior, and the reward / value heads pick up signal as it actually arrives.

This is a maximum-entropy argument, formally: among all distributions on $\{1, \dots, N\}$ with no prior knowledge, the uniform $\mathbf{1}/N$ minimizes KL divergence from any later-learned target on average — and is the unique fixed point of "no information yet." Hafner's choice to operationalize this via $W = 0$ (rather than, say, sampling $W$ from a high-variance prior and projecting) is the cheapest possible implementation: one line of init code, zero forward-pass cost.

**Verified.** The justification is sound; the implementation expresses it correctly.

### Critical point 4 — bias zero-init via `jnp.zeros` (not via `uniform_init_weights`)

Sheeprl's `uniform_init_weights(0.0)` zeros *both* the kernel (via `nn.init.uniform_(weight, -0, +0)`) and the bias (via `bias.data.fill_(0.0)` — see `vendor/sheeprl/.../utils.py:L179-L180`). The CP3 JAX port splits these: the kernel goes through `uniform_init_weights(0.0, ...)` (Eq. 1'), the bias goes through `jnp.zeros((out_features,), dtype=jnp.float32)` directly (`agent.py:L268`, L336).

Mathematically these are identical — both produce all-zeros at the same shape and dtype. The split is a JAX-side ergonomic choice (the helper returns a kernel-shaped array; binding the bias separately avoids returning a tuple). The fixture (CP3 fixture generator at `gen_cp3_fixtures.py:L111-L112`) asserts the *sheeprl* side has both kernel and bias zeroed by sheeprl's own helper, and the test compares the JAX bias against this zero bias — so any drift between the sheeprl path and the JAX `jnp.zeros` path would surface as a non-zero `bias_diff`. It does not; `max_abs_diff = 0.0` covers both fields.

**Verified.** Bias-init math is equivalent; the split is cosmetic.
