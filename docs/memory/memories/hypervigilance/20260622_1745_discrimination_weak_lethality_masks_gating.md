# Discrimination weak (refuted at threshold); lethality masks the hunger-gate

## Key conclusion
Across the 10-run olfactory_ambiguity sweep (200-episode eval each, decay_power 2.0), the agent **never
learned meaningful pre-contact discrimination**: a small, statistically-real avoidance tilt (~+0.1 to
+0.21 cell, the agent lets the rabbit drift closer and flees the predator slightly more) switches on the
moment smells differ (s=0.05) but **never reaches the pre-registered 0.5-cell bar** — H1a (discrimination
onset) refuted at threshold, no onset s*. Hunger-gating (H1b) is also refuted, **but** the predator is
lethal and the agent dies in 47-69% of episodes, so per the pre-registered watch-out the honest reading is
**"the lethal [5,120] predator likely prevented a hunger-gate from being reinforced," not "no gate
exists."**

## Evidence, measurements, facts
- Closest-approach gap (predator-minus-rabbit, cells): anchor hg01 (s=0,sigma=0) = +0.01 [-0.12, +0.13]
  (CI includes 0 -> **clean null, no vision-count-elimination leak**); separated runs +0.13 to +0.21, all
  below 0.5; max = hg08 (s=0.5,sigma=0.2) +0.21 [+0.12, +0.29]. H1a_pass = False on all 10.
- Hunger-gating gap (satiated-minus-hungry closest-approach) on sigma>0 runs ~0 or NEGATIVE (hg06 -0.15
  [-0.26, -0.04], the wrong direction). Death rates 47-69% on those runs.
- Mechanism (trajectory cross-check agrees with the means): the agent survives by **reactive tank-and-hide**
  (predator orbits at distance 1 while it eats/rests/bush-dives, injury oscillates 0->35->0), NOT by
  pre-emptive standoff. Visual is contact-only, so olfaction is the sole distal cue and it is used weakly.
- Single training seed (42) -> the surface is **provisional**; multi-seed hardening pending.
- Raw per-run numbers: `tmp/20260620_164156_hunger_gated_step1_results.json` (analysis via experiment-analyzer).
