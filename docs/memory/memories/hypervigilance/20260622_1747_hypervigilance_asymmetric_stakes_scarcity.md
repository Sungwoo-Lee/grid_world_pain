# Hypervigilance via asymmetric stakes + food scarcity (not a danger count ratio)

## Key conclusion
To make the agent **pre-emptively avoid** (the hypervigilance signature), the redesign keeps a **1:1
predator:rabbit** world (chosen for clean analysis, not a danger-dominant count ratio) and instead drives
danger-dominance through **asymmetric stakes**: under high olfactory ambiguity, mistakenly **approaching the
predator = death** ([5,120]) while mistakenly **avoiding the rabbit = a missed meal** that now actually
hurts because **food is scarce**. Scarce food removes the "camp somewhere safe" option and **forces the
stay-vs-flee decision**.

## Evidence, measurements, facts
- `configs/environment/experiment/hypervig_scarcity/`: 2 configs (`01-scarce`, `02-abundant`) differing ONLY
  in the food block. Scarce: 2 sources (diagonal corners), `max_consumption 4`, `regeneration_delay 40`.
  Abundant (the "can camp safely" baseline): 8 sources, `max_consumption 12`, `regen 0`.
- Both fixed at **high ambiguity** s=0.05 / sigma=0.4 (predator `[0,0.55,0.45,0,0]`, rabbit `[0,0.45,0.55,0,0]`,
  std `[0,0.4,0.4,0,0]`), lethal [5,120], randomized starts (nutrition [10,100], injury [0,80]).
- Scarcity is "tight but survivable": ~+480 net nutrition vs ~500 metabolic drain over 500 steps —
  survivable only if the agent forages well, so hunger genuinely pressures the decision.
- Both arms trained to 10M episodes (wandb `hypervig_scarcity`: scarce `v2r40wdz`, abundant `thkwm11m`).

## Decisions and actions
- The scarce-vs-abundant contrast isolates the food-scarcity effect; the abundant arm is the camp-able
  reference.
- **Watch-out carried forward:** lethal predator + scarce food pushes the agent *into* danger more, so the
  same "lethality masks gating" risk from [[20260622_1745_discrimination_weak_lethality_masks_gating]]
  applies — pre-decided that a high hungry-start death rate means "too punishing," not "no hypervigilance."
  (Auditor note: split deaths by starvation vs injury before concluding.)
