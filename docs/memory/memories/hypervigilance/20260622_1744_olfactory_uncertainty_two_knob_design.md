# Olfactory uncertainty designed as two orthogonal knobs (separation x noise)

## Key conclusion
The hunger-gated / olfactory-ambiguity training program isolates a single independent variable — how
distinguishable the predator and rabbit smell — and splits it into **two orthogonal knobs**: mean
**separation s** and per-episode **noise sigma** (`properties_std`). Everything else is held byte-identical
to the cell-08 contrast (1 predator + 1 rabbit, matched chase, lethal [5,120], disengage, contact-only
vision, randomized starts, abundant food), so any behavioural difference traces to smell alone.

## Evidence, measurements, facts
- Symmetric smell scheme (no presence/absence giveaway): predator `[0, 0.5+s, 0.5-s, 0, 0]`, rabbit the
  mirror `[0, 0.5-s, 0.5+s, 0, 0]`, `properties_std = [0, sigma, sigma, 0, 0]` on channels 2 & 3 of both.
- 10-config grid: s in {0, 0.05, 0.1, 0.25, 0.5} x sigma in {0, 0.2, 0.4}. s=0 = identical smell; s=0.5 =
  orthogonal (values clip-bounded to [0,1], so 0.5 is the max separation; s=0.5 with sigma>0 has one-sided
  clipped jitter -> treat as anchor, not onset rung).
- Smell is drawn **once per episode** at reset (`src/environment/core.py` `_sample_property` inside
  `jax_reset`), held fixed within the episode. Consequence: **sigma=0 = reducible/learnable** mapping (a
  trained agent can in principle nail it); **sigma>0 = irreducible** ambiguity (the same smell can be a
  predator one episode and a rabbit the next; only resolvable by risking contact). The hunger-gated
  decision lives in the sigma>0 regime.
- Visual is contact-only (`visual_sensor_range: 0`), so **smell is the sole distal class cue** -> smell is
  the right thing to manipulate.
- A pinned-predator scheme was rejected: it would make one channel a binary "rabbit present" flag,
  trivialising the gap at any s.

## Decisions and actions
- Configs at `configs/environment/experiment/olfactory_ambiguity/` (renamed from `hunger_gated/` on
  2026-06-22 because the set varies olfactory discriminability, not hunger).
- Initial-state randomization (nutrition + injury) was added as a **prerequisite, not an IV**, so
  hunger-gating is learnable across the full hunger range (see [[20260619_0113_configurable_initial_state_ranges]]).
- The empirical result of this design is captured separately in [[20260622_1745_discrimination_weak_lethality_masks_gating]].
