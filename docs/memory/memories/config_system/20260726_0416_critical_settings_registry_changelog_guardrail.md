# Critical-settings registry + dated change log as a silent-drift guardrail

## Key conclusion
To stop high-impact config values from drifting silently (as `decay_power` did — see [[20260726_0415_decay_power_silent_drift_reverted_1p0]]), created `docs/environment/CONFIG_CRITICAL_SETTINGS.md`: a **registry** of the settings that most change agent behavior (canonical value + config path + meaning) and a **dated change log**. The binding rule: changing a registry value REQUIRES a same-commit change-log entry (date, path, old->new, reason, blast radius); a missing entry is a flagged regression. It carries a Maintenance Contract and is wired as required reading into the config/training agents.

## Evidence, measurements, facts
- Registry seeded with `sensory.decay_power=1.0`, `sensory.sensor_radius=20`, `sensory.vector_size=5`, `body.death_penalty=100`; grows on evidence.
- Wired into 5 agent profiles (`env-config-auditor`, `experiment-designer`, `training-runner`, `developer`, `senior-developer`) with a "read the registry before config/launch work; enforce the logging protocol" line each, plus one bullet in project `CLAUDE.md`.
- **Context-efficiency was an explicit requirement.** Three levers: (1) the CLAUDE.md bullet is loaded EVERY turn -> trimmed from a 5-line backstory to ONE pointer line (backstory lives only in the doc's change log); (2) agent-profile lines are conditional ("read before config/launch work") and load only when that agent is spawned; (3) the doc itself compacted 72->28 lines, registry table front-loaded so actionable values are read first. Net standing cost = one line/turn; the 28-line read happens only during actual config/launch work.
- Same shape as the earlier CONFIG_GUIDE.md Maintenance Contract pattern, applied to a new concern (drift auditing vs authoring).

## Decisions and actions
- Committed doc + `decay_power` revert together (the change-and-log-in-one-commit protocol the doc mandates), then a separate commit compacted the doc + trimmed the CLAUDE.md bullet, then the agent-profile/CLAUDE.md wiring commit.
- Registry is intentionally short; add a row when a new high-impact setting is identified.
