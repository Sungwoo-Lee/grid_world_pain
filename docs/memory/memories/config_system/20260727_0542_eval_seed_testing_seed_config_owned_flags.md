# Eval seed must be testing.seed, not the training seed; config-owned flags stay off the CLI

## Key conclusion

Three chained lessons. (1) The user noticed rPPO eval videos contained predators but Dreamer's did not: both trainers derive eval identically (PRNGKey(seed)→split→reset), and the difference was only the SEED VALUE — rPPO runs used 42 (draws a predator at episode 1), our Dreamer launches passed --seed 0 (episode-1 reset draws ZERO predators on basic03 AND basic04, re-seeded fresh at every checkpoint → permanently predator-free eval videos). Measured on one frozen checkpoint: mean eval length 348 (seed 0, 2/3 episodes predator-free, rides the 500 cap) vs 28 (seed 42) — a 12x apparent-performance swing from the seed alone. (2) The RIGHT fix was not a new key: configs/evaluation/default.yaml already carried testing.seed: 8217 (honoured by the standalone evaluator, ignored by training-time eval). Commit `b228117` points both trainers' checkpoint-eval at it; 8217 draws predators in all three eval episodes [2,1,2]. (3) Root cause of the root cause: I passed --seed 0 on the CLI, overriding config seed 42 — violating the documented config-owns-values convention (train_command-agent.sh: --num-envs/--seed/--checkpoint-frequency must NOT be passed on standard launches; deviations must be flagged). Same bug class as the historical --num-envs 16 silent shadow.

## Evidence, measurements, facts

- Predator draw at episode-1 reset (basic03): seed 0 → [0,2,2]; seed 42 → [1,0,1]; seed 8217 → [2,1,2]. Base rate: 33% of resets have zero predators (131/400).
- Verified from recordings (animal_pos; [10,10] = off-grid parking), not from summary metrics.
- Verification trap re-confirmed: Config.load_yaml does NOT resolve extends: — checking the experiment_on.yaml preset with it falsely showed testing.seed=None; train.py uses load_env_config (resolves extends) and both presets give 8217. Never verify a trainer's config with a different loader than the trainer uses.

## Decisions and actions

- b228117: in-training eval == standalone eval == both algorithms on testing.seed. Future launches omit --seed (config 42 governs training; 8217 governs eval).
