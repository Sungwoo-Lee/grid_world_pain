# Configurable initial-state randomization ranges (conditional-mandatory)

## Key conclusion
The agent's start `nutrition` and `injury` randomization bounds — previously hardcoded to `max/2` in `jax_reset` (so a randomized start could only ever be in the upper half of nutrition / lower half of injury) — are now config keys `body.start_{nutrition,injury}_{low,high}`. They are **conditional-mandatory** (Fork B2): read via `get_mandatory` ONLY when the matching `random_start_*` flag is true. Since no config sets those flags true, there is ZERO ripple — all configs and the parity suite are untouched. This unlocks genuinely hungry (<50) and badly-injured (>50) starts, which makes frozen-checkpoint eval probes in-distribution and makes hunger-gated risk-taking learnable.

## Evidence, measurements, facts
- **Forks chosen**: A1 (four flat scalar keys, matching the flat `body` convention) · B2 (conditional-mandatory) · C1 (the dead `random_start_satiation` key left as a documented no-op; satiation stays DERIVED from nutrition, so `start_nutrition`/its range is the only hunger lever).
- **JAX**: the four new fields are PLAIN `float` traced leaves on `EnvParams` (NOT `pytree_node=False`) → vmap-safe, no recompile on value change. Validated.
- **Validation at load (eager)**: `0 <= low <= high <= max_{nutrition,injury}`; `low>high` and a missing range key when the flag is on both raise `ValueError`.
- **Verified via ParallelEnv**: hungry band `U[0,30]` → draws 0.11–29.99 (all <50); injured band `U[60,100]` → 60.13–100 (all >50); satiation correctly derived (max 29.99 when hungry); flags-off start byte-unchanged (100/0); an `extends:` child inherits the base range when it flips the flag.
- `default.yaml` carries the four keys EXPLICITLY (full `[0, max]`) with flags off, so they are inert documentation that `extends:` children inherit; the user chose explicit-in-base over strict-omit. 6 new tests; full env suite 0 failures.

## Decisions and actions
- Authoring opt-in training configs that actually flip the flags is `experiment-designer` work (e.g. for the hunger-gated-avoidance study), not part of this code change.
