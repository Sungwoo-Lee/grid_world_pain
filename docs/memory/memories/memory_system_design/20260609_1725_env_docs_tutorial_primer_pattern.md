# Shared-primer + per-doc-callout pattern for tutorial-grade reference docs

## Key conclusion
To make a set of reference docs double as a learnable tutorial without bloating every file, use a two-layer structure: (1) one shared primer doc that teaches each advanced API exactly once, each section behind a stable HTML anchor; (2) each subject doc embeds its functions' full verbatim source with a `> API notes` callout that deep-links to the relevant primer anchors, adding only doc-specific first-principles. Re-sync the docs to code-as-truth BEFORE adding the teaching layer, and add a "how to read these / learning path" section to the hub. This extends the project's plain-language documentation-framing policy from "explain the question in English" to "explain the implementation in teachable English."

## Evidence, measurements, facts
- Built `docs/environment/00_jax_primer.md` (~960 lines, 15 anchored sections: pytrees/`struct.dataclass`, static fields & recompilation, `jit`, `jit(static_argnames)`, `vmap`/`in_axes`, PRNG `split`/`fold_in`, `.at[].set()`, branchless `where`/`select`/`cond`, `tree_map`, `lax.scan`, `one_hot`, masking, `linalg.norm`, the static-index-tuple scatter idiom, Orbax). Stable anchors via explicit `<a id="slug"></a>` so docs can link `[primer: vmap](00_jax_primer.md#vmap)`.
- Anchors were predefined and handed to all doc-writing agents up front, so links wired correctly without coordination.
- Each of docs 01-13 got per-function verbatim embeds + primer-linked `> API notes` callouts; the hub (`ENVIRONMENT_SUMMARY.md`) got a "How to read these docs" learning-path section and the primer as TOC row `00`.
- Doc set roughly doubled to ~12,000 lines; primer placement avoided re-teaching e.g. `vmap` in all ~9 JAX-heavy docs.
- Audience target encoded in every agent prompt: competent Python+RL dev, new to JAX; skip basic Python, teach only the advanced APIs.

## Decisions and actions
- Adopt this as the default shape when asked to make reference docs "introductory / tutorial": primer-once + verbatim-embeds + primer-linked callouts + hub learning path.
- Sequence matters: phase 1 = re-sync docs to current code (code is source of truth); phase 2 = add the teaching layer. Do not teach against stale docs.
- Predefine the primer's anchor slugs before fanning out doc agents so cross-links are deterministic.

## Open questions and follow-ups
- Whether to generalize the primer beyond `src/environment/` (e.g. a project-wide JAX primer the algorithm docs also link).
