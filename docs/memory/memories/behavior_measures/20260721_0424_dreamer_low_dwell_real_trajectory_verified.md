# Dreamer near-zero bush-dwell is real, not a pipeline bug

## Key conclusion
When the basic04 Dreamer size-sweep dwell curves came out ~0% everywhere, the worry was a pipeline artifact (bush mislocated, degenerate policy, agent never reaching the exact cell). Trajectory inspection - in both the simplified probe AND the real training env - confirms it is a **genuine "the agent has not learned it yet"**, not a bug. The eval pipeline is sound: `episode_measures` correctly registers the exact steps the agent sits on the bush (it reads 2% in the no-threat case, 0 under threat), the bush is correctly recorded, and the agent moves on 90%+ of steps (not frozen). The size-S Dreamer at 66k episodes on basic04 simply dies fast to the ranged predator (5-68 steps, injury jumps to 100) and never reaches cover; in the safe no-predator case it survives all 500 steps and even heals. A 100M-trained rPPO agent on the same training env does the opposite - flees to the bush under threat and heals (cover use 9/10 episodes; e.g. 2 predators -> 93.6% in bush, injury 50->0). The gap is training, not the measure.

## Evidence, measurements, facts
- Animal-slot map is `['predator','predator','neutral','neutral']` (2 predator slots); a slot is "active" if its recorded position varies across the episode. **Predator randomization works**: 8/10 Dreamer episodes and 5/10 rPPO episodes had an active predator; the earlier "only no-predator videos" was the ~1/3 zero-predator rolls (count randomized 0-2), not a config/seed bug.
- Untrained Dreamer size-S (ckpt 66k, basic04 training env, max_steps 500): no-predator episodes survive 500 steps and heal (injury 26->0, 80->0); predator episodes die in 5-68 steps with injury -> 100. Mature pred_inj00 dwell <8% for all 5 sizes; survival 15-30 steps.
- Trained rPPO (`rppo_basic04_jump_128env_100M`, ckpt 100M): cover use 9/10 episodes; injury trends down (50->0, 96->6); 4 episodes survive all 500 steps; eval_rollout flagged 108 threat-onset events with real bush-dive / eat-under-threat responses.
- Positive control: the SAME `episode_measures` on the same `.rec.gz` format yields 30-60% dwell for trained rPPO agents - the measure fires when camping exists.
- Cross-level olfaction control (rabbit_olfzero = chasing rabbit with smell removed) collapses camping to ~0-5% across all levels/sizes while predator-smell on a harmless wanderer partly restores it - bush-hiding is olfaction-driven, confirming [[20260630_1717_avoidance_reflex_needs_motion_and_olfaction]] at scale.
- Videos saved: `results/eval/{rppo_basic04_jump_100M,dreamer_basic04_size_s}_trainenv_video/`.
