# Behavior-probe eval sped ~8.8x: parallelism dominates, batched rollout adds a bit, render needs an FD fix

## Key conclusion
The frozen-checkpoint avoidance probe pipeline was sped ~8.8× end-to-end, measured with a controlled A/B/C benchmark. The dominant lever is PARALLELISM (6.1×): the 72 cold-process JAX startups (~14 s each) were the real cost, not the rollout. A batched single-process `--batched` rollout (vmap ParallelEnv + `nnx.jit` `lax.scan`) adds a further ~1.45× on top — but only reveals its value inside the parallel pool, because in isolation startup still dominates. It was landed behind a flag and parity-verified bit-for-bit. Separately, parallel matplotlib video render must raise its own file-descriptor limit or it crashes.

## Evidence, measurements, facts
- A/B/C benchmark (12 configs of one model, 30 eps each): **A** sequential+legacy 273 s → **B** 14-way parallel+legacy 45 s (**6.1×**) → **C** 14-way parallel + `--batched` 31 s (**8.8×**). Full 6-model sweep ~27 min → ~3 min.
- Per single config: ~14 s startup + ~13 s rollout — startup dominates, which is why batching alone measured ~1× wall-clock in isolation but pulls its weight once startups overlap.
- **nnx.jit trap** (the parity-critical bug): after `nnx.update(model, restored)`, an EAGER `model(x,h)` reads a subtly-wrong view of the restored weights (even though `nnx.state` checksums identically); a bare `lax.scan` around an eager call does NOT fix it — the scan body must be wrapped in `nnx.jit`. The legacy path is safe only because its forward entry `get_action_and_value_nnx` is `@nnx.jit`-decorated.
- Parity: 90/90 episodes bit-for-bit (all 11 measures + raw arrays) across 3 checkpoints × 4 configs; legacy left verbatim + default.
- **FD fix**: `render_recordings.py` raises `RLIMIT_NOFILE` at startup (background/non-interactive contexts impose ~1024 soft limit; each matplotlib render opens ~70–105 fds; parallel renders crash `OSError Errno 24` without it). Added `--max-episodes`/`--stride` for representative renders.

## Decisions and actions
- Committed the batched rollout + parity harness (`fa9ada0`), FD-safe render + subset flags (`7ddacb7`). Verified via senior-developer parity gate + code-reviewer JAX pass.
- Decided AGAINST a Tier-2b in-process driver (one JAX import for the whole sweep) — the sweep is already ~3 min; the marginal ~1 min saved is noise next to the (now-decoupled) video render.
