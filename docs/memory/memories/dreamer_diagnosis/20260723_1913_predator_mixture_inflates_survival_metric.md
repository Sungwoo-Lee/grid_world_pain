# The basic04/03 training-survival metric is a predator-presence MIXTURE, not a competence measure

## Key conclusion
basic04 (and basic03) declare the hunting predator with `count_low: 0, count_high: 2`, so each episode independently samples 0, 1, or 2 predators — roughly **one-third of episodes have NO predator at all**, and `max_steps=500`. The WandB survival mean is therefore a **bimodal mixture**: ~1/3 of episodes forage safely toward the cap (~400 steps) and ~2/3 die to the predator (~20 steps), averaging ~130-150 — which is what we watched climb to ~133. That number is ~97% driven by the no-predator third; it measures "can it forage when nothing hunts it," NOT "can it survive predators." The Dreamer model-size verdict drawn from this metric ("S is the sweet spot; bigger is worse") is an **artifact and is retracted**.

## Evidence, measurements, facts
- Config: `configs/environment/experiment/basic/04-jump_attack_10x10.yaml` predator entity `count_low: 0 / count_high: 2`; basic03 identical. basic02 by contrast is fixed `count: 1` (no mixture there).
- Predator-conditioned probes (parallel session, `scripts/eval/dreamer_srl_probe_eval.py`) at `results/eval/avoidance/metrics_history_dreamer_basic04_size/<size>/avoid_{none,pred}_inj00.csv`:
  - `avoid_none` (no predator), ALL Dreamer sizes: survival **101** (capped), injury **0**.
  - `avoid_pred` (predator present), Dreamer XS/S/M/L/XL: survival **21.6 / 16.5 / 27.2 / 16.6 / 20.5**, injury **100 / 100 / 100 / 100 / 97**, bush-use **0.10 / 0.07 / 0.37 / 0.00 / 0.83**, closest_approach 0.0 (predator reaches the agent).
  - rPPO szXS `avoid_pred`: survival **96.7**, injury **14**, bush-use **1.00** — the ONE agent that hides is the one that lives.
- Conditioned-on-predator ranking is **M 27 > XS 22 > XL 21 > L≈S 17** — all failures, and S (the "training winner") is nearly worst.

## Decisions and actions
- Retracted the size verdict; terminated all 5 basic04 Dreamer size runs on the user's call ("not showing proper performance").
- Established that the trustworthy metric is the **predator-conditioned probe**, not the WandB survival mean.
- Queued a **predator-conditioned survival metric** (split survival by predator count) as the top follow-up — no logging/smoothing fix helps this; only conditioning does.
