# Bush `blocks_animals` toggle — animal-impassable refuge (movement-only, default off)

## Key conclusion
A "bush" is an obstacle with `blocking: false` + `hides_agent: true`. Today it gives **behavioural**
safety only — a hunting predator that sees the agent enter a bush **loses interest and returns home**
(`agent_hidden`), but animals are **not physically excluded** from bush cells. Added a new per-obstacle
flag **`blocks_animals`** (default `false`) that makes the obstacle impassable to **animals only**: it is
OR'd into the hunt + wander collision check, while `move_agent` keeps using plain `obs_blocking` so the
**agent can still enter and hide**. Default-off is byte-transparent (`obs_blocking | False == obs_blocking`).

## Evidence, measurements, facts
- Config -> params: `obs_blocking` / `obs_hides_agent` loaded at `config_loader.py:986-987`.
- Agent movement `core.py:move_agent` collides only on `obs_blocking`; bushes are `blocking:false` -> agent
  enters freely.
- Concealment in `_hunt_step` (`core.py:199-214`): `agent_hidden` (agent on an active hides_agent cell)
  blocks `become_hunt` and forces `lose_interest`.
- Gap: animal movement collision (`_hunt_step:265`, `_wander_step:315`) used `obs_blocking` only, so animals
  could move onto bush cells; a predator on the agent's cell still bites.
- Implementation (commit `523364a`, Phase 1 movement-only): new `EnvParams.obs_blocks_animals` (traced bool
  array); `update_animals` computes `obs_block_for_animals = obs_blocking | obs_blocks_animals` and feeds it
  to `_hunt_step`/`_wander_step` (no signature change); `move_agent` untouched. 4 new tests pass; parity
  GREEN with **no fixture regen** (default-off byte-identical).

## Decisions and actions
- Per-obstacle toggle (matches existing `blocking`/`hides_agent` pattern), default off so existing configs
  are unchanged; set `blocks_animals: true` on bushes to turn the refuge on.
- Phase 2 "spawn-exclusion" turned out unnecessary -> [[20260624_0517_bush_spawn_exclusion_free_via_overlap_resolution]].
