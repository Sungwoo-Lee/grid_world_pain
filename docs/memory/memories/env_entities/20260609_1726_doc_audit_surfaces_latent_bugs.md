# Code-as-truth env-doc audit surfaced ~13 latent code findings

## Key conclusion
Rewriting documentation against the implementation (code = source of truth) is itself a low-cost bug discovery pass: forcing every function's behaviour onto the page exposes places where the code diverges from apparent intent. The full v2.0 re-sync of the 14 `docs/environment/` docs surfaced ~13 latent findings (none changed — flagged for the user to triage), captured in a working file. The two most actionable are real correctness/telemetry issues, not cosmetics.

## Evidence, measurements, facts
- Most actionable:
  - **`overeating_death` is a no-op** (`core.py`, jax_step termination block): sets termination reason code 3 when satiation hits max, but never sets `done=True` — the episode labelled "overeating-dead" never actually ends.
  - **`info['termination_reason']` unreliable when a body system is disabled** (`core.py` ~542-545): starvation (code 2) and injury (code 4) reason assignments lack the `with_nutrition`/`with_injury` guard the `done` flag has, so reason codes mislabel or spuriously fire in ablation configs.
- Other items: `last_action` reset can index out of bounds in a no-rest+no-eat config; silent `(0,0)` placement fallback on spawn-area exhaustion (`core.py:694`); `auto_reset_step` ignores its `key` arg (`wrapper.py:35`); `placement_mode` validated with `assert` (disabled under `python -O`); dreamer-srl checkpoints omit optimiser state; tautological no-op conditional in `jax_reset` (`core.py:955`); duplicate `res_*` assignment in `renderer.py:447-455`; dead `dist` + unsorted offsets in `get_visual_offsets` for sensor_range>1; zero-delay resource respawn is off-by-one.
- Full triage list (4 severity tiers): `tmp/20260608_154726_env_doc_audit_suspected_bugs.md`.
- Method: 14 parallel sub-agents each rewrote one doc against its mapped source and returned a "suspected code bugs" section; findings were consolidated.

## Decisions and actions
- Kept code untouched (user's instruction: flag, don't fix); offered to route confirmed bugs to senior-developer for fix plans.
- Treat code-as-truth doc rewrites as a deliberate bug-finding tactic, not just a documentation chore.
