# Predator behavioural parameters are per-episode rangeable ([lo,hi]); move_interval + attack_delay added

## Key conclusion
Animal behavioural fields can be redrawn EACH EPISODE by writing `field: [lo, hi]` instead of a scalar. Five were already wired by the v2.0 unified-entity refactor (`DISTRIBUTIONAL_FIELDS` in config_loader.py: detection_range, max_stamina, stamina_recovery_rate, hunt_stamina_threshold, lose_interest_multiplier) — parsed scalar-or-[lo,hi], sampled at reset via `jax.random.uniform` into `animal_*_sampled`, consumed in _hunt_step. This session ADDED `move_interval` and `attack_delay` (integer timers) to the same pattern, sampled per-episode via `jax.random.randint(key,(N,),lo,hi+1)` (the +1 makes `hi` inclusive). A plain scalar is stored as a degenerate range `[s,s]` and is genuinely deterministic (`uniform(s,s)=s`; `randint(s,s+1)=s`), so every timing field can use the SAME `[lo,hi]` expression with `[x,x]` meaning "fixed". `nociception_intensity` deliberately left a fixed scalar. damage is per-EVENT (re-sampled each hit), not per-episode.

## Evidence, measurements, facts
- Extension (commit bd3c8e5): EnvParams gains animal_move_int_low/high + animal_attack_delay_low/high; EnvState gains animal_move_int_sampled + animal_attack_delay_sampled; jax_reset samples both (ep_keys split 5->7); _hunt_step/_wander_step use the sampled move_interval and the damage block uses the sampled attack_delay. Recompile-safe (traced int leaves), vmap-safe. 8 new tests; parity suites green (scalar -> degenerate -> identical draw).
- Independent behavioural verification (temporary experiment, no training): move_interval 1/2/3 -> predator advances col 6/3/2 in 6 steps (genuine cadence, runtime uses SAMPLED value not the old fixed one); post-hit attack_timer == sampled attack_delay (2,3,4). Degenerate [2,2]/[3,3]/[4,4] pin to the constant in both sampling and behaviour.
- Applied to level 05 (commit 033c255): predator detection_range [1,7], move_interval [1,3], attack_delay [1,3] (rabbit untouched). 500 resets confirm all three sample per-episode.
- The other 4 float fields are one YAML edit ([lo,hi]) from randomizing — no code needed.

## Decisions and actions
- User chose to extend ONLY move_interval + attack_delay (not nociception_intensity), and to keep the uniform [lo,hi] expression with degenerate ranges for deterministic values.
